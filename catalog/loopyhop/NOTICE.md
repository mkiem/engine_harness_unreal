# loopyhop design references

Two design references by **loopyhop**, included in Engine Harness with the author's permission:

- **Gameplay Atlas** (https://gameplayatlas.loopyhop.com): `mechanics.json`, 280 game mechanics in 28 groups. Each has
  its rules, core loop, player decisions, design parameters, real game cases, combinations, a walkthrough and
  prototype guidance.
- **Game Art Style** (https://gameartstyle.loopyhop.com): `art-styles.json`, 37 visual styles. Each has a definition,
  what to look for, a global art-direction prompt and reference games.

Rebuilt with `node scripts/import-loopyhop.ts`. Credit loopyhop and link the source page when showing an entry
(the studio tools do).

**Game screenshots are not included.** They belong to each game's rights holders, and loopyhop's permission cannot
cover them. Every game reference keeps its official store page or wiki link instead. Game names and trademarks belong
to their owners. The mechanic and style descriptions are editorial analysis, not claims about the original
developers' intentions.

The atlas's own guidance applies to anything made with these references: study the style, respect the work, and use
original designs. Do not copy a particular game's characters, logos or artwork.
